# Bosnië in Beeld

Een Nederlandstalige, filmische ontdekkingstocht die automatisch afspeelt in ongeveer twee minuten, langs Mostar, de stećci en de grot Vjetrenica.

Open `index.html` in een browser en de film begint vanzelf. De `bronnen.html`-pagina bevat de oorspronkelijke UNESCO-bronnen. Opmaak en animaties staan los in `css/style.css`; de automatische tijdlijn staat in `js/film.js`.
